Use this skeleton for every Guided Practice. Paste into [`practice-log.md`](practice-log.md) under the matching day (sections are already stubbed).

```markdown
## Guided Practice N – <Title>
**Date:** YYYY-MM-DD
**Repo:** https://github.com/shafakyildiz/spring-bookstore (local: `spring-bookstore/`)
**Time spent:** ~__ min

### Context
<!-- What were you asked to do? One short paragraph. -->

### Evidence / Work
<!--
Days 1–6: classes, endpoints, request flow, Postman timings, diffs summary
Days 7–12: facts, hypotheses, risk tables, review comments, artefacts referenced
-->

### Engineering Judgment
<!-- Why these decisions? Trade-offs? What you rejected and why. -->

### Outcome / Recommendation
<!-- Done criteria for this day: feature shipped, smell documented, Approve/Reject, next action, etc. -->

### Self-check
- [ ] Mandatory concepts understood (from day guide brief)
- [ ] Mandatory exercise completed
- [ ] This log section filled with evidence
```

## Field mapping to program “How to Record”

| Program asks for | Put it under |
|------------------|--------------|
| Repository / endpoint / classes | Evidence / Work |
| Request flow | Evidence / Work |
| Smell / measurements / cache design | Evidence / Work |
| Why / impact / trade-offs | Engineering Judgment |
| Production recommendation / Approve-Reject | Outcome / Recommendation |
| Checklists | Self-check |

---

## Writing bar (keep it sharp)

- Prefer **class and method names** over vague “the service layer.”
- Prefer **numbers** (ms, SP, error %) over adjectives (“slow”, “risky”).
- Prefer **one clear recommendation** over a laundry list.
- Never paste AI output you have not validated.
